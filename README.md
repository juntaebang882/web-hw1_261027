HTML 섹션 제목(h2)과 카드 제목(h3)의 태그 계층 구조 정리
어려웠던 점: 메인 페이지에 두 개의 섹션(mine, boxoffice)을 도입하면서 시멘틱 마크업 규칙에 맞게 섹션 제목은 h2로, 개별 카드 내부의 영화 제목은 h3로 정확히 분기하여 수정하는 작업이 헷갈렸습니다.
해결 방법: 과제 안내서의 HTML 구조 가이드를 바탕으로 <main> 하위의 각 섹션 제목과 카드 내부의 타이틀 태그 레벨을 검토하여 일괄 교체하고, 이와 연동되는 CSS 선택자도 함께 수정하여 마크업 일관성을 유지했습니다.

CSS 변수(:root) 선언과 var() 함수를 통한 스타일 속성 일괄 교체
어려웠던 점: :root 전역 변수 선언 방식과 색상/글꼴 속성을 일일이 var() 함수로 감싸서 적용하는 문법이 생소하여 적용 과정에서 오타나 누락이 발생하기 쉬웠습니다.
해결 방법: 스타일시트 맨 위에 :root 블록을 두고 배경색, 표면색, 글자색 및 포인트 색상을 변수로 명확히 정의한 뒤, 파일 전체의 색상 속성을 var(--bg), var(--surface), var(--text) 등으로 꼼꼼하게 치환하여 코드의 유지보수성을 높였습니다.

상세 페이지(detail.html) 내 정의 목록(<dl>) 구조 설계
어려웠던 점: 상세 페이지에서 영화의 다채로운 정보(제목, 원제, 개봉일, 평점, 줄거리 전문)를 교재 3.3절의 목록 만들기 규칙에 맞추어 dt와 dd 쌍으로 구조화하는 방법이 생소했습니다.
해결 방법: 교재의 정의 목록 마크업 예시를 참고하여 <dl> 태그 내부에 항목 이름은 <dt>, 설명 내용은 <dd>로 다섯 쌍을 정확히 짝지어 배치하고, CSS 그리드 속성과 연계해 정돈된 정보 영역을 구축했습니다.
